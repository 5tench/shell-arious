# Scripts

This folder is for runnable general-purpose scripts.

Older setup notes and drafts have been moved to `notes/` so this folder can stay focused on scripts that are closer to ready-to-run.

## Current Scripts

| File | Purpose |
| --- | --- |
| `install-guest-additions.sh` | Installs VirtualBox Guest Additions on Debian/Ubuntu or RHEL-family systems after the ISO is mounted. |
| `text-explorer.sh` | Searches and samples text files from a directory. |

Run `./script-name --help` when supported, and read the file before using it on a real system.
